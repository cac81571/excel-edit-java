# WBS実績入力

Excel の WBS シートに対して、日付ごとの予定・実績時間を入力するデスクトップアプリです。

担当者や項目名で絞り込み、親 WBS を残したまま自分の作業行だけを編集できます。

## 必要環境

- Java 17 以上
- Maven 3.9 以降（ビルド・開発時）
- Windows を想定（日本語フォント・Excel 連携）

## 起動方法

### 実行可能 JAR

```powershell
mvn -DskipTests package
java -jar target\wbs-editor.jar
```

Excel ファイルを引数で渡せます。

```powershell
java -jar target\wbs-editor.jar C:\path\to\wbs.xlsx
```

### 開発時

```powershell
mvn exec:java
```

## 主な使い方

1. Excel ファイル（`.xlsx` / `.xls`）のパスを入力するか **参照** で選び、**読み込み** を押す（ドラッグ＆ドロップでも読み込み可）
2. **担当** を選ぶ（空欄なら全件。指定時は自分の作業と親 WBS が表示されます）
3. 必要なら **項目名** で部分一致フィルタ、または **実績ありのみ** で実績が入っている行だけ表示（該当作業の親 WBS も残ります）
4. **日付**（`YYYYMMDD`）を選び、黄色いセル（予定／実績）に時間を入力
5. **保存** する

### 操作のポイント

| 操作 | 内容 |
|------|------|
| 日付欄に入力 | `YYYYMMDD` などで直接指定（Enter またはフォーカス移動で確定） |
| 上下矢印（日付） | 日付を 1 日ずつ増減 |
| Ctrl+C | 選択セルの内容をコピー（WBS No・項目名など） |
| Delete | 予定／実績セルをクリア |
| 配置設定 | シート名・行・列の位置を変更 |

- 入力した時間は Excel 上で `0.00` 形式で書き込まれます
- 選択中の日付の列が Excel に無い場合は、列は追加せずエラーを表示します

## 保存とバックアップ

保存の直前に、既存ファイルを次の場所へバックアップします。

```text
%USERPROFILE%\WBS実績入力\backup\
例: wbs_sample_20261004_160945.xlsx
```

保存完了時に、バックアップのパスもダイアログに表示されます。

## 想定する Excel レイアウト（初期値）

| 項目 | 初期値 |
|------|--------|
| 日付の行 | 2 行目（例: `10月1日`） |
| 曜日の行 | 3 行目 |
| データ開始行 | 4 行目 |
| Level / WBS No / 項目名 / 担当 / 予定・実績 | A / B / C / D / E 列 |
| 日付の開始列 | F 列〜 |

各 WBS は「予定」「実績」の 2 行構成を想定しています。レイアウトが違う場合はメニューの **設定 → シート配置** で合わせてください。

## 設定の保存場所

設定はレジストリではなく、ユーザーホーム配下のプロパティファイルに保存します。

```text
%USERPROFILE%\WBS実績入力\settings.properties
```

保存内容の例:

- シート配置（日付行、開始列、予定／実績ラベルなど）
- 最後に開いたファイル／フォルダ
- 最後に選んだ担当者

## テスト

```powershell

```
